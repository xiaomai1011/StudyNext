# 参考项目与学习通开放能力调研

调研日期：2026-11-11。调研目标是理解同类产品的信息架构、任务模型与工程组织，不复制不兼容许可证代码，也不把未确认的接口能力描述成已实现功能。

## 1. 参考项目

### 1.1 Cooanyh/chaoxing-list

- 地址：https://github.com/Cooanyh/chaoxing-list
- 形态：JavaScript 用户脚本/浏览器扩展式工具。
- 许可证：AGPL-3.0。
- 主要能力：聚合学习通待办、作业、考试与课程任务，提供集中列表视图。
- 可借鉴点：以“跨课程任务聚合”为核心信息架构；截止时间优先；把课程作为任务归属而不是独立孤岛。
- 复用结论：**未复制代码**。AGPL-3.0 具有较强传染性，且用户脚本运行环境与本项目 Electron 架构不同。StudyNext 独立实现领域模型、SQLite 存储与 React UI。

### 1.2 mshzy/study_assistant

- 地址：https://github.com/mshzy/study_assistant
- 形态：Flutter 桌面/移动端学习助手。
- 许可证：MIT。
- 主要能力：账号数据同步、课程任务、DDL 提醒、桌面小组件等。
- 可借鉴点：任务与课程分离、提醒预设、桌面端常驻、同步状态需要明确区分。
- 复用结论：**未复制代码**。技术栈为 Dart/Flutter，无法直接用于 Electron/React；仅参考产品功能划分与提醒交互。MIT 代码若未来复用需保留版权与许可声明。

### 1.3 helloene/chaoxing-xuexitong-student-portal

- 地址：https://github.com/helloene/chaoxing-xuexitong-student-portal
- 形态：静态入口导航页。
- 许可证：MIT。
- 主要能力：集中展示学习通首页、课程、作业、考试、通知、课表等官方入口。
- 可借鉴点：入口分类与命名；官方页面优先、应用只做导航与隔离承载。

## 3. 学习通官方开放能力

调研对象：

- https://open.chaoxing.com/
- https://open.fanya.chaoxing.com/
- 学习通官网与帮助中心公开页面

观察结果（仅代表调研时点）：

1. `open.chaoxing.com` 出现重定向循环，未呈现可用的开放平台文档首页。
2. `open.fanya.chaoxing.com` 落到 `nonexistent.html` 一类的不存在页面。
3. 公开官网未发现面向个人开发者的 OAuth 应用注册、课程/作业/考试数据接口申请入口。
4. 未找到可公开访问的“个人开发者可申请课程与作业 API”的正式说明。

结论：

- **不能确认个人开发者可以自助申请学习通 OAuth 与课程/作业数据接口。**
- 因此 StudyNext 不实现基于抓包得到的私有接口，也不把网页 DOM 抓取包装成“官方同步”。
- `ChaoxingAuthorizedAdapter.isConfigured()` 固定返回 `false`；未配置时同步状态为 `not_configured`，UI 明确显示“未配置学习通授权数据源”。
- 真实接入需要学习通开放平台或机构合作方提供正式授权、接口文档、回调地址与审核流程。接入前应完成隐私政策、数据最小化、令牌安全存储与撤销机制。
- 当前稳定替代方案：手动任务、CSV 导入、ICS 日历导入、隔离的官方网页视图。

## 4. 数据模型借鉴与独立实现

借鉴的是概念，不是代码：

- 课程：名称、代码、教师、学期、分类、颜色、收藏、课表。
- 任务：标题、描述、课程归属、类型、优先级、状态、截止时间、来源。
- 提醒：任务 + 分钟偏移 + 启用状态；与任务一对多。
- 通知投递：task + rule + dueAt 去重，支持改期后重新提醒。
- 同步：显式状态机 `not_configured / syncing / success / partial / failure`。

所有模型在 `src/shared/types.ts` 定义，SQLite schema 在 `src/main/storage/store.ts`，UI 不直接依赖任何学习通私有字段。

## 6. 安全与合规边界

StudyNext 的目标是改善个人学习管理体验，不替代或干扰学习通的服务规则：

- 不使用用户账号进行自动化学习、签到、答题或监考规避。
- 不绕过验证码、风控、反爬或访问控制。
- 不读取、导出或上传用户 Cookie/Token。
- 远程页面运行在独立沙箱会话，不能访问本地数据库与 Electron API。
- 登录由用户在官方页面手动完成；应用只承载页面。
- 未授权数据源保持“未配置”，不以演示数据冒充真实同步。

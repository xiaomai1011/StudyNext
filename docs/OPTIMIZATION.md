# StudyNext 0.2.0 会话优化落地记录

来源：用户在 2026-11-11 分享的 ChatGPT 会话
`https://chatgpt.com/share/6af42e50-4400-83ea-8af5-26412150e24f`。本文件记录其中可落地的产品要求、取舍与当前实现，不把未授权能力描述为已完成。

## 1. 从会话提取的目标

会话讨论的是一款 MyGo 原生学习通客户端，核心诉求包括：

1. 现代桌面体验：统一课程、任务、DDL、通知、日历与官方页面入口。
2. 学习中心：课程 → 章节 → 学习点（阅读/视频/测验/讨论）的进度视图。
3. 题目/作业辅助：题库、解析、可选 AI 解题思路。
4. 数据接入：本地优先；在取得正式授权前，不依赖私有协议或未授权接口。
5. 可靠提醒：运行中提醒、启动补发，以及明确说明退出后的限制。
6. 安全边界：官方网页隔离、URL 白名单、凭据不入日志、默认不上传个人数据。

## 2. 技术取舍

| 会话方向          | 本版选择                           | 原因                                                                                                                                     |
| ----------------- | ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| MyGo 原生重写     | 保留 Electron 38 + React 19 桌面壳 | 现有工程已具备完整窗口、托盘、SQLite、提醒、Portal 隔离和可安装产物；直接重写会丢弃已验证的稳定能力。MyGo 仍可作为后续独立数据服务候选。 |
| 自动刷课/自动答题 | 不实现                             | 需要未授权的私有接口、验证码/风控绕过或代答，超出本项目的兼容层边界。                                                                    |
| 学习通实时同步    | 保持 `not_configured`              | 未找到面向个人开发者公开可申请的 OAuth/课程接口；不使用抓包得到的私有接口。                                                              |
| 学习数据          | 新增 JSON 学习快照导入             | 可离线、可验证、可审计；导入来源明确标为 `import`，不伪装成实时同步。                                                                    |
| 题目助手          | 本地题库 + 可选 OpenAI 兼容 API    | 用户自带 Key，Key 使用 `safeStorage` 加密；仅用户主动请求时发送当前题目。                                                                |
| 参考资料          | 仅做功能与许可调研                 | `xuexitong-cli`（MIT）提供只读数据函数思路；`uXueScript`（GPL-3.0）不复制代码。                                                          |

## 3. 已落地功能

### 3.1 学习中心

- 侧栏按课程浏览，搜索课程/章节/学习点。
- 每门演示课程 3 章、每章 4 个学习点；演示数据共 15 章、60 个学习点。
- 学习点支持完成/取消完成，章节进度按学习点实时重算，不依赖可能过期的快照百分比。
- 显示课程数、学习点数、已完成数与整体进度。
- 空状态提供“导入学习快照”入口。

### 3.2 学习快照导入

支持根对象或 `data` 包装的 JSON，结构示例：

```json
{
  "courses": [
    {
      "externalId": "course-001",
      "name": "数据结构与算法",
      "code": "CS201",
      "teacher": "王砚秋",
      "chapters": [
        {
          "externalId": "chapter-001",
          "title": "第 1 章 · 基础概念",
          "points": [
            {
              "externalId": "point-001",
              "title": "章节导读与学习目标",
              "kind": "reading",
              "durationMinutes": 10,
              "completed": true
            }
          ]
        }
      ],
      "homeworks": [
        {
          "externalId": "hw-001",
          "title": "实验三：图的最短路径",
          "dueAt": "2026-11-20T23:59:00+08:00"
        }
      ]
    }
  ]
}
```

- 课程、章节、学习点按 `(course_id, source, external_id)` 去重。
- 作业/考试转为统一任务，任务外部 ID 带课程前缀，避免跨课程冲突。
- 导入结果返回新增/更新/跳过计数、警告和结构化错误。
- 来源固定为 `import`；仪表盘、标题栏和设置页显示“本地快照 · 非实时同步”。

### 3.3 题目助手

- 题目卡 CRUD、课程归属、标签、答案、解析、来源记录。
- 搜索题目/答案/标签，按课程筛选。
- AI 设置：启用开关、Base URL、模型、API Key、清除 Key。
- 仅支持 HTTPS Base URL（localhost HTTP 便于本地模型），请求路径为 `/chat/completions`。
- Key 经 `safeStorage` 加密后保存；不写日志、不进入渲染器持久化、不随题库导出。
- AI 答案展示模型名，可一键保存为题目卡。

### 3.4 数据来源与 UI 语义

- 实时学习通适配器：`not_configured`，状态说明“需要正式授权数据源”。
- 本地 JSON 快照：来源 `import`，显示“本地快照 · 非实时同步”，不会出现“已连接学习通”措辞。
- CSV/ICS：保留原有手动导入能力。
- 演示数据：`demo`，明确标注为本地演示。

## 4. 未实现 / 后续

- 真实学习通 OAuth、课程/作业 API：未获公开个人开发者授权文档，继续等待机构合作或正式 API。
- 自动刷课、签到、考试代答、验证码绕过、反爬、监考绕过：不实现。
- MyGo 数据服务：可作为独立本地 sidecar 评估，当前不替换 Electron。
- 学习快照的定时拉取、增量同步、冲突合并：仅保留手动导入，避免把未知来源数据当作实时同步。
- AI 服务商的模型质量、费用、数据保留策略由用户自行选择；应用不内置共享 Key。

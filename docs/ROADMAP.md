# StudyNext 下一阶段计划

## 当前基线（0.3.0）

- 第一阶段桌面应用、仪表盘、课程、任务、DDL 提醒、日历、SQLite、演示数据已完成。
- 学习中心已完成：课程 → 章节 → 学习点、完成进度、搜索、空状态。
- 题目助手已完成：本地题库 CRUD、课程/标签/来源、可选 OpenAI 兼容 AI，Key 使用 `safeStorage`。
- 学习通兼容层安全基础设施已完成：隔离 `WebContentsView`、会话分区、URL 白名单、跳转/权限/下载拦截、系统浏览器回退。
- CSV/ICS/JSON 学习快照导入、授权适配器接口、同步状态机已完成；真实学习通同步仍为 `not_configured`。
- Windows NSIS 安装包已可生成。

## 阶段 A：真实数据接入的前置条件（阻塞项）

真实接入不是纯代码工作，必须先取得以下材料：

1. 学习通开放平台或机构合作方的**正式授权**。
2. OAuth/接口文档：授权地址、token 地址、scope、回调白名单、刷新策略。
3. 课程、作业、考试、通知字段的正式定义与分页规则。
4. 数据使用范围、隐私条款、用户删除/撤回机制。
5. 允许的客户端类型与 User-Agent/回调协议要求。

在上述材料缺失时，保持 `not_configured`，不以抓包接口、网页 DOM 抓取或私有签名替代。

## 阶段 B：授权与数据适配器

### B1. OAuth 客户端

- 使用系统浏览器或隔离窗口完成授权码流程。
- 回调只接受已登记的自定义协议/本地回环地址。
- token 使用 Electron `safeStorage` 加密后存储；日志中只记录状态，不记录 token。
- 实现刷新、撤销、过期、网络失败与用户退出的完整状态。
- 明确 `not_configured / syncing / success / partial / failure` 的 UI。

### B2. 数据映射

新增 `ChaoxingAuthorizedAdapter`：

```ts
class ChaoxingAuthorizedAdapter implements AuthorizedDataAdapter {
  isConfigured(): boolean
  pull(since?: string): Promise<CourseBundle>
}
```

映射规则：

- 课程：官方 id → `externalId`，名称/教师/学期/课表 → `Course`。
- 作业/考试：官方 id → `Task.externalId`；截止时间统一转 ISO；类型映射为 `homework/exam`。
- 通知：只读元数据；正文不落库，避免存储敏感内容。
- 增量同步使用官方游标/更新时间；全量同步提供节流与断点。
- 冲突策略：本地手动修改优先，官方更新写入 `sync_conflicts` 等待用户选择；不静默覆盖用户数据。
- 部分成功：按对象类型返回成功/失败计数与错误原因。

### B3. 安全与隐私

- 最小 scope；不请求成绩、个人信息、监考等非必要字段。
- 令牌不进入渲染器、不写入 SQLite 明文、不进入崩溃日志。
- 同步默认手动触发，可配置周期；退出登录时清除 token 与缓存。
- 提供“导出我的数据”“删除全部远程同步数据”。
- 所有网络请求只访问文档列出的官方域名，禁止重定向到未知域。

## 阶段 C：真正的退出后提醒

当前提醒只在主进程存活时运行。若产品需要退出后提醒，可选方案：

1. **Windows 任务计划程序**：注册每日/登录时任务，启动一个轻量提醒进程；需要处理安装、升级、卸载清理与权限。
2. **常驻托盘进程**：关闭窗口不退出，托盘常驻；已有 `closeToTray`，但用户完全退出后仍不提醒。
3. **本地通知服务**：独立 Windows 服务，权限更高，安装复杂，需代码签名与安全评估。

推荐先做方案 1，并满足：

- 不把提醒逻辑复制成两套；复用 `findDueReminderCandidates` 与 SQLite。
- 任务创建/修改/删除后同步更新计划任务。
- 卸载时删除计划任务与数据目录（询问用户是否保留数据）。
- UI 明确显示“退出后提醒已启用/未启用”，不夸大能力。

## 阶段 D：体验完善

- 课程详情增加任务聚合与成绩入口（仅授权数据）。
- 日历支持单双周、调休、节假日、拖拽改期。
- 任务批量完成/删除、归档、搜索历史。
- ICS 导出、打印周计划、系统分享。
- 通知操作按钮：完成、稍后提醒、打开详情。
- 数据备份/恢复（SQLite 导出、加密选项）。
- 学习快照字段映射向导、导入预览、增量合并与冲突提示。
- 题库批量导入/导出、错题复习队列、AI 结果引用来源。
- 可访问性：键盘导航、焦点环、屏幕阅读器标签、减少动效。
- 评估 MyGo 本地数据 sidecar，但不替换经过验证的 Electron 桌面层，除非有明确的性能/分发收益。

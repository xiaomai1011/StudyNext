# StudyNext 路线图

> 路线图按主题与优先级组织，不承诺具体发布日期。当前状态以 [STATUS.md](STATUS.md) 为准。

## 当前基线（v0.5.0，2026-11-25）

- Electron + React + TypeScript + SQLite 桌面应用，保持 `WebContentsView` 隔离与 Portal 持久会话。
- 学习通 Web Session 只读同步覆盖课程、作业、课表、章节、学习点、考试、通知、资料；资料支持下载与本地核验。
- 作业工作流覆盖官方页面内编辑、附件上传、草稿保存、提交检测、作业记录、成绩与教师批语。
- 平台状态六态：`not_submitted / submitted / pending_review / reviewed / done / unknown`；平台状态与本地完成状态分离。
- 自动刷新由 `useSyncScheduler` 驱动：启动检查、前台周期、后台恢复、失败退避，可配置 3/5/10/15 分钟或关闭。
- Studio UI 已完成：三顶层标签“今天/课程/作业”、课程工作台、全局搜索、命令面板、浅/深主题与自由缩放。
- 系统级 DDL 提醒已实现：进程内调度 + Windows Task Scheduler 无头检查 + 失败持久化重试。
- 多账号：DPAPI 凭据、账号切换、每账号独立 SQLite 工作区、只读历史库保护。

## v0.5.x 收尾

### P0 数据正确性

1. `PortalSubmitEvent → retryCourse → Provider → Normalizer → SQLite → IPC → Renderer` 链路可观测、可回归测试。
2. 部分响应不覆盖已有成绩、满分、教师批语、附件、截止时间、`sourceUrl`。
3. 单课程重试不伪装成全量同步；旧请求不覆盖新数据；失败保留最后有效状态。
4. 真实账号提交作业后自动刷新为“待审核”，完成作业后平台状态正确变化（由用户本人验收）。

### P1 同步与提醒体验

1. 同步中心显示自动刷新开关、间隔、上次同步、数据新鲜度、最近错误、手动同步。
2. 任务中心与作业记录显示数据更新时间。
3. 同步导航守卫：同步前页面快照、同步后恢复；用户主动操作页面时不覆盖。
4. 失败报告区分网络、登录过期、安全验证、部分课程失败。
5. Windows 安装/覆盖升级/卸载、Task Scheduler 定时触发、真实通知点击的目标环境验收。

### P2 UI 与工程一致性

1. 统一浅色/深色 token、字体层级、状态色、控件高度、间距、圆角、阴影、边框与交互状态。
2. 今天、课程、作业、记录、设置页完成视觉收口。
3. 清理遗留 P2：资料管理、搜索定位、旧 todo 与目录完成冲突、App.tsx 细粒度定位接线。
4. 保持测试、文档、截图与当前实现同步。

## v0.6 学习闭环

- 资料批量下载、下载队列、失败原因持久化与断点恢复；资料分页真实验证。
- 章节学习点进度与官方页面跳转体验；不伪造进度、不自动刷课。
- 作业提交前校验、本地草稿与复杂题型兼容；继续坚持官方页面提交。
- 课程/作业/通知的增量同步、细粒度错误报告与可恢复失败。
- 复杂课表：单双周、调休、节假日、多教师与多时段建模。

## v0.7 多平台与正式发布

- 多 Provider 抽象：保留学习通深度集成，同时支持其他教育平台适配器。
- 正式发布：代码签名、自动更新策略、安装/升级/卸载完整验收、品牌视觉定稿。
- 数据导入/导出与跨设备迁移（需用户明确授权与隐私设计）。
- 可观测性：同步/解析失败诊断包，默认脱敏，不包含账号、Cookie、Token。

## 长期维护原则

1. **真实优先**：真实账号验证由用户本人执行；Mock/单测通过不等于真实平台通过。
2. **诚实状态**：未配置、失败、部分成功不得显示为成功；任何页面打开成功不增加同步计数。
3. **安全边界**：不绕过验证码、MFA、监考或教师权限；不伪造学习记录、签到或提交；不暴露 Cookie/Token。
4. **官方页面写操作**：作业编辑、上传、草稿、提交留在官方页面；应用只做导航、检测与回读。
5. **文档随代码更新**：功能、架构、测试基线变化时同步更新长期文档；不再保留过程报告。
6. **小步可回滚**：每次变更保持可运行、可测试、可回滚；不先做大重构再补验证。

## 验收原则

- 每个版本至少通过 `npm run typecheck`、`npm test`、`npm run build`；涉及 Electron/窗口/Portal/持久化时运行 `npm run test:e2e`。
- 发布前在真实 Windows 环境验证安装、覆盖升级、卸载、通知与 Task Scheduler。
- 真实学习通账号验收必须覆盖登录、同步、作业提交、成绩/批语回读、资料下载与会话过期。
- 每阶段记录完成情况、自动化测试、真实账号验证、剩余问题与 Git 状态。

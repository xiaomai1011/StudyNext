# 学习通数据接入能力矩阵（v0.4.0）

- 版本：0.4.0 研究基线
- 日期：2026-11-12
- 适用范围：StudyNext 当前 C 路线（Electron 桌面客户端 + 官方页面兼容层 + 可插拔 Provider）
- 结论：官方接口未获证实；当前能力以用户手动导入和官方页面访问为主；实时同步必须等待正式授权。

## 1. 判定图例

| 标记               | 含义                                                                                                      |
| ------------------ | --------------------------------------------------------------------------------------------------------- |
| `官方授权可用`     | 已有可核验的官方 OAuth/API 文档、scope、测试环境，并且 StudyNext 已完成接入验证。当前没有一项达到此状态。 |
| `机构授权后可用`   | 技术上可通过学校/超星机构合作获得，但尚未取得书面授权、接口文档或测试账号，不能写成已实现。               |
| `用户手动导入`     | 用户主动提供 JSON 快照、CSV 或 ICS；导入后在本机使用，不冒充实时同步。                                    |
| `仅官方页面可访问` | 只能在隔离的 `WebContentsView` 中由用户本人查看；不抓取、不解析页面内容作为同步结果。                     |
| `暂时不可实现`     | 目前既没有授权接口，也没有可靠的用户导出方式；不以网页抓取替代。                                          |

## 2. 能力矩阵

| #   | 能力         | v0.4.0 当前判定  | 授权后的目标   | 当前实现/证据                         | 说明                                                                               |
| --- | ------------ | ---------------- | -------------- | ------------------------------------- | ---------------------------------------------------------------------------------- |
| 1   | 课程列表     | 用户手动导入     | 机构授权后可用 | JSON 快照 `courses`；本地课程页       | 支持课程名、教师、分类、来源；不自动读取学习通账户                                 |
| 2   | 课程详情     | 用户手动导入     | 机构授权后可用 | 快照课程字段 + 官方页面               | 快照不保证包含教学大纲、班级、学分等完整详情                                       |
| 3   | 作业列表     | 用户手动导入     | 机构授权后可用 | JSON 快照 `homeworks` / `assignments` | 可合并为任务；不是从作业接口实时拉取                                               |
| 4   | 作业截止时间 | 用户手动导入     | 机构授权后可用 | 快照 `dueAt` + 截止变化检测           | 现有 `upsertImportedTask` 能检测截止变化并清理旧通知                               |
| 5   | 作业提交状态 | 仅官方页面可访问 | 机构授权后可用 | Portal 官方页面                       | 当前快照解析不读取提交状态、得分、批语；不能显示“已提交”                           |
| 6   | 考试列表     | 用户手动导入     | 机构授权后可用 | JSON 快照 `exams`                     | 作为 `kind='exam'` 的任务进入 DDL 管理                                             |
| 7   | 考试时间     | 用户手动导入     | 机构授权后可用 | 快照考试时间字段                      | 不包含考场、座位、准考证等未定义字段                                               |
| 8   | 课程公告     | 仅官方页面可访问 | 机构授权后可用 | Portal 课程页/通知入口                | 没有公告模型、全文同步或已读状态                                                   |
| 9   | 学校通知     | 仅官方页面可访问 | 机构授权后可用 | Portal 通知入口                       | 首页“最近通知”是模拟数据，不能当作真实学校通知                                     |
| 10  | 章节目录     | 用户手动导入     | 机构授权后可用 | JSON 快照 `chapters`；学习中心        | 章节外部 ID 按课程隔离，支持重复导入更新                                           |
| 11  | 学习点       | 用户手动导入     | 机构授权后可用 | JSON 快照 `points`；学习点勾选        | 本地 `status` 记录是否完成；平台真实完成来源和进度尚未接入                         |
| 12  | 学习进度     | 用户手动导入     | 机构授权后可用 | 快照 `progress` + 本地学习点进度      | 快照百分比与本地完成数可能不同，界面以本地完成数计算章节进度，并保留快照值来源说明 |
| 13  | 课件和资料   | 仅官方页面可访问 | 机构授权后可用 | Portal 官方页面                       | 当前无资料模型、文件列表或下载任务；不从页面提取链接                               |
| 14  | 课程课表     | 用户手动导入     | 机构授权后可用 | JSON 快照 `schedule`；CSV/ICS；日历   | 周次、星期、节次、地点为快照字段；真实课表需授权接口                               |

## 3. 逐项结论

### 3.1 可以真实交付的能力

以下能力在 v0.4.0 当前版本可以由用户主动导入后真实使用：

- 课程列表与基本详情
- 作业列表与截止时间
- 考试列表与考试时间
- 章节目录、学习点、章节进度
- 课程课表

边界是“导入后本地使用”，不是“已登录学习通自动同步”。导入结果必须在同步中心显示为 `import`，并显示导入时间和文件名。

### 3.2 只能通过官方页面访问的能力

- 作业提交状态、得分、教师批语
- 课程公告
- 学校通知
- 课件和资料
- 需要登录后才可见的课程页面内容

StudyNext 只提供隔离的官方页面入口，不解析页面、不注入脚本、不自动点击。登录由用户本人完成；导航日志去掉 query/hash 后再展示。

### 3.3 需要正式授权后才能设计的能力

所有实时 API 能力都先标记为“机构授权后可用”，而不是“已实现”：

- 课程/章节/任务/考试/通知/课表/资料的服务端读取
- 增量游标和分页
- Token 刷新、撤销和机构审计
- 提交状态和真实学习进度
- 通知推送或变更订阅

## 4. Provider 能力声明建议

Provider 不应通过“是否能打开网页”来判断能力，而应显式声明：

```ts
type AccessLevel = 'official' | 'institutional' | 'manual' | 'web_only' | 'unavailable'

interface ProviderCapabilities {
  courses: AccessLevel
  courseDetail: AccessLevel
  homework: AccessLevel
  homeworkDeadline: AccessLevel
  submissionStatus: AccessLevel
  exams: AccessLevel
  examSchedule: AccessLevel
  courseAnnouncements: AccessLevel
  schoolNotices: AccessLevel
  chapters: AccessLevel
  studyPoints: AccessLevel
  progress: AccessLevel
  materials: AccessLevel
  schedule: AccessLevel
}
```

约束：

- `official` 只能在有文档、scope、测试账号和成功回归后设置。
- `institutional` 只能在书面授权和接口文档到位后设置。
- `manual` 由用户主动导入触发，不产生“自动同步”状态。
- `web_only` 只能打开官方页面，不能把页面内容转成领域对象。
- `unavailable` 必须显示“暂不可用”，不能伪造空成功。

## 5. 同步状态语义

| 状态               | 触发条件                         | UI 必须显示                       |
| ------------------ | -------------------------------- | --------------------------------- |
| `not_configured`   | 没有 Provider 授权或没有手动导入 | 未配置/本地模式，不得显示“已连接” |
| `syncing`          | 正在读取已授权数据源             | 进度与当前资源                    |
| `success`          | 所有请求资源成功，且结果已落库   | 成功数量、时间、来源              |
| `partial`          | 部分资源成功、部分失败或冲突     | 成功/失败资源、冲突数、可重试项   |
| `failure`          | 关键请求失败或没有可用结果       | 错误摘要、本地数据未受影响        |
| `import`（来源值） | 用户导入 JSON 快照               | 本地快照，不是实时同步            |

## 6. 不能标记为可用的项目

- 未获授权的网页接口读取
- 自动登录、验证码识别/绕过
- 自动刷课、伪造学习记录
- 自动考试答题、代交作业
- 把官方页面打开成功当成数据同步成功
- 用第三方项目（包括 xuexitong-cli）替代官方授权证明
- 将模拟通知或演示课程显示成真实学习通数据

## 7. 验收口径

在正式授权到位前，v0.4.0 验收只看：

1. 手动导入能稳定更新课程/章节/学习点/任务，并正确标记来源。
2. 同步中心不出现“已连接学习通”的假状态。
3. 官方页面入口保持隔离，危险导航被拦截，日志脱敏。
4. 未配置 Provider 时所有实时入口显示“暂不可用”。
5. 任何页面打开成功都不会增加“同步成功”计数。
